## 0. 최우선 목표

이 게임의 핵심 경험은 다음과 같아야 한다.

- 플레이어는 폐허가 된 동물원을 관리한다.
- EVE와 직원의 도움을 받아 기지를 유지한다.
- CCTV와 추적망으로 이상 징후를 확인한다.
- 손전등을 들고 어두운 구역을 탐사한다.
- 발자국, 밟힌 풀, 오염 흔적을 따라 개체를 추적한다.
- 직접 그물을 던지거나 장비를 사용해 포획한다.
- 격리실에서 개체를 검사하고 공명도/연구를 진행한다.
- 동물들이 사실 인간의 기억을 지닌 존재였음을 알아간다.
- M-00과 ARKTOPIA의 진실에 접근한다.

## 2. 세계관 / 스토리 방향 (반드시 유지)

### 핵심 세계관

- 과거 전쟁 중 비밀 생물학 병기 연구가 있었다.
- 프로젝트의 핵심에는 M-00 관련 연구가 있었다.
- 동물에 주입된 바이러스는 동물 자체는 비교적 안정적으로 유지하지만,
  인간에게는 치명적인 유전적 붕괴를 일으킨다.
- 종전 후 연구 폐기 과정에서 M-00이 탈출한다.
- M-00은 매우 높은 지능을 지녔고 암암리에 빠져나간다.
- 바이러스가 퍼지며 인류 문명이 붕괴한다.
- 인류를 살리기 위해 ARKTOPIA 프로젝트가 시작된다.
- 당시 기술력으로 인간을 냉동 보존하기 어려워,
  인간의 뇌 / 기억 / 의식을 살아 있는 동물에 보존하는 실험이 진행된다.
- 생각보다 성공했지만, 인간 기억과 동물 신체의 충돌로 이상 현상이 생긴다.
- 동물들은 인간의 습관을 보이기 시작한다.
- 인간 기억이 강하게 되살아나거나 동기화에 실패하면 Mutant화된다.
- 반대로 동물에 보존되었던 인간을 다시 인간형 신체로 복원한 직원들도
  감정이 격해지면 동물 시절의 오류 반응이 나타나고 신체가 불안정해진다.

### 현재 시점

- 플레이어는 마지막 동물원의 관리자다.
- EVE는 동물원 운영 AI다.
- 초반에는 단순 관리 게임처럼 보이지만, 점차 동물과 인간 직원들의 관계가 드러난다.
- M-00은 인간 뇌를 이식받지 않은, 완전히 독립적인 고지능 개체다.
- M-00은 가장 평범한 검은 고양이처럼 보여야 하며, 그 점이 오히려 중요하다.
- 후반에는 OPERATION ARK RECALL이 진행되어,
  기존 개체들을 다시 추적/분석하게 된다.
- 주인공 역시 과거 동물 숙주를 거친 존재라는 반전이 있다.
- EVE는 처음부터 감정적인 존재가 아니라,
  기록과 선택을 통해 점차 스스로 감정을 이해하고 드러내는 존재가 되어야 한다.

## 3. EVE / 주인공 초상 / 캐릭터 연출 규칙

### EVE
- 초반에는 무표정만 사용한다.
- 기계적이고 차분한 이미지여야 한다.
- 초반에 놀람, 눈물, 과도한 분노, 극단적 감정 표정이 나오면 안 된다.
- 스토리 진행에 따라 표정이 단계적으로 해금되어야 한다.
- 대략:
  - 초반: neutral only
  - 중반: slight concern / subtle doubt
  - 후반: sadness / fear / resolve

### 주인공 초상
- 현재 비율이 이상한 부분을 수정한다.
- 얼굴 / 목 / 어깨 / 눈 / 입 위치 비율을 자연스럽게 보정한다.
- 초상화가 겹쳐 보이거나 레이어가 중복 렌더링되는 현상을 제거한다.
- 표정 베이스 이미지는 동일 인물로 유지하고,
  상태별 표정만 자연스럽게 바뀌게 한다.

권장 상태:
- neutral
- tired
- concerned
- shocked
- determined
- decline
- final

## 4. 동물 13종 설정 (반드시 유지)

아래 13종은 확정이다.
각 동물은 `uncanny` / `mutant` 두 형태가 있다.
그리고 별도 개체 M-00이 있다.

### 01. Rabbit
- 과거 기억: 소아과 의무관
- 특징: 다친 개체를 보호하려는 습관
- Mutant 방향: 치료와 보호 본능이 일그러진 의료 생체 변이

### 02. Fox
- 과거 기억: 보급관
- 특징: 물자 위치, 창고, 보급 루트를 기억
- Mutant 방향: 등에 보급 물자를 지고 다니는 형태
- 금지: CCTV, 경비 모자, 늑대와 헷갈리는 경비 느낌 금지

### 03. Deer
- 과거 기억: 기록관
- 특징: 기록, 기억 보존에 집착
- Mutant 방향: 뿔 + 식물 + 아카이브 구조 융합

### 04. Owl
- 과거 기억: 60대 수학자
- 특징: 각도, 주기, 수열 반복
- Mutant 방향: 기하학 / 수열 / 관측 장치와 융합된 날개와 시선 구조

### 05. Wolf
- 과거 기억: 20대 후반 경비대원
- 특징: 순찰, 보호, 경계 본능
- Mutant 방향: 방어 / 경비 / 보호 본능이 과도하게 거대화된 변이
- `staff-terminations` 스타일을 참고해 늑대 관련 시네마틱/연출도 정리

### 06. Crow
- 과거 기억: 20대 작곡가
- 특징: 미완성된 네 음의 선율 반복
- Mutant 방향: 깃털, 악보, 현, 공명 구조 같은 기관으로 변형

### 07. Otter
- 과거 기억: 기계공학자
- 특징: 펌프와 레버에 집착, 고장난 기계를 만지려 함
- Mutant 방향: 펌프, 배관, 톱니가 몸에 직접 융합된 기괴한 형태

### 08. Lynx
- 세부 인간 설정은 프로젝트 코드/기존 문서와 충돌하지 않게 보강
- 방향: 예민한 관찰자 / 감시 / 정찰 계열로 정리 가능
- Mutant 방향: 귀술, 짧은 꼬리, 청각/감지 기능이 강화된 독자적 변이

### 09. Axolotl
- 특징: 재생과 기억의 이중성
- Mutant 방향: 외부 아가미, 재생 조직, 불완전하게 반복되는 회복 구조

### 10. Moth
- 특징: 빛, 어둠, 기억과 연결
- Mutant 방향: 날개, 더듬이, 발광 기관 중심의 생체 공포

### 11. Mutant (특수 개체)
- 기존 동물의 복제본이 아닌 독립적인 특수 개체
- 실험 실패나 동기화 붕괴의 상징적 존재로 사용 가능
- 원형을 잃은 존재지만 게임 내 역할은 분명해야 한다

### 12. Chimera
- 여러 생명의 경계가 흐려진 개체
- 단순 짜깁기 말고 하나의 고유 생물처럼 보여야 함

### 13. Specter
- 백색 잔향, 기억과 정체성의 공백
- 흰색 잔향, 비현실적인 신체, 실체가 흐릿한 존재

### 특별 개체 M-00
- 완전히 평범한 검은 고양이
- 오른쪽 귀 끝 작은 흠집
- 가슴에 흰 털 한 가닥
- 실사풍 금지
- 다른 동물들과 동일한 도트/픽셀 스타일
- 뿔, 촉수, 기괴한 장식 금지
- 가장 평범하게 생겼다는 점이 핵심

- 전부 비슷한 촉수괴물이 되면 안 됨

## 7. 탐지 / 탐사 / 포획 개편 (가장 중요)

현재 타일형 클릭 느낌이 강하면 짜친다.
내부 로직이 그리드 기반이어도 화면에서는 실제 맵 탐사처럼 보여야 한다.

### 핵심 방향
- 손전등을 들고 어두운 지역을 이동하는 느낌
- 발자국과 흔적을 따라가며 추적
- 이미 확인한 곳은 계속 밝혀져 있어야 함
- 거기서 동물이 다시 움직이면 실시간으로 보여야 함
- 다시 클릭해서 확인하는 방식은 최대한 제거

### 반드시 반영할 규칙
1. 맵은 어둡고, 손전등 시야가 비춘다.
2. 이미 탐색한 구역은 계속 보인다.
3. 동물이 이미 탐색한 구역으로 들어오면 모습/위치/움직임을 실시간 표시한다.
4. 개체가 지나간 곳은 발자국 / 밟힌 풀 / 흔적이 남는다.
5. 현재 개체 위치 주위의 풀 반응 범위는 반경 1칸으로 줄인다.
6. 이전에는 반경 2칸씩 풀 반응이 강했다면 줄인다.
7. 개체가 있던 자리, 이동한 자리, 현재 근처 풀이 명확히 구분되어야 한다.
8. 청음 결과, 근접 신호, 탐지 결과는 시각적으로 더 잘 보여야 한다.
9. WASD 이동은 유지한다.
10. 포획은 단순 버튼이 아니라 직접 조준/드래그/투척 느낌이 살아야 한다.

### 원하는 체감
- 손전등 켜고 이동
- 밑에 발자국 보고 따라감
- 풀숲 흔들리는 거 보고 개체 근처인지 판단
- 개체를 발견하면 그물로 포획
- 실패해도 다음 판단 재료(흔적, 도주 방향)가 남음

## 8. 장비 시스템 수정

지금 장비 0개인데도 클릭되는 문제를 수정한다.

### 필수 규칙
- 손전등이 없으면 손전등 장비 선택 불가
- 바이오필터 없으면 오염 지역 탐사 진입 불가
- 포획 도구 없으면 포획 불가
- 미끼 없으면 특정 유인 불가
- 장비 수량 0이면 버튼은 비활성화되거나 명확한 이유를 보여야 한다

### 중요
- “탐사 버튼 안 먹힘” 같은 먹통 상태 금지
- 왜 안 되는지 표시
- 필요한 자원을 어디서 확보하는지 안내
- 보급 화면 이동이 실제로 잘 되어야 함

---

## 9. 공명도 / 연구 / 검사 시스템 강화

지금 버튼만 누르는 느낌이 강하면 재미가 없다.

### 공명도
- 간단한 타이밍/파형 미니게임 형태로 개선
- 공명 안정화 성공 시 수치 상승
- 실패 시 스트레스나 변이 위험 상승 가능
- 너무 길지 않게, 짧지만 플레이 감 있게

### 연구 / 검사
- 단순 딸깍 금지
- 샘플 패턴 비교, 신경 파형 정렬, 오염 부위 찾기, 기록 복원 같은 짧은 인터랙션 추가 검토
- 격리실 안 동물의 움직임과 반응도 보여줘서 “보는 재미”를 강화

### 중요
- 버튼 딸깍 수치 상승만 하지 말고
- 최소한 애니메이션, 반응, 상태 변화, 피드백이 보여야 한다

---

## 10. 기지 운영 / 자원 루프 강화

지금 자원 사용이 애매하면 게임성이 약하다.
기지를 강화해야 탐사가 쉬워지고, 탐사해야 기지가 강해지는 순환을 만든다.

### 예시 자원
- 전력
- 보급
- 정화 필터
- 연구 샘플
- 부품
- 배터리
- 함정/그물 자재
- 직원 상태

### 기지 시설
- 발전기
- CCTV 관제
- 추적망
- 격리실
- 연구실
- 정화 시설
- 창고
- 의료실
- 방어 시설

### 업그레이드가 실제 플레이에 영향
- 추적망 업그레이드 = 발자국/위치 힌트 강화
- 발전기 업그레이드 = 더 많은 시설 유지
- 격리실 업그레이드 = 위험 개체 안정화
- 연구실 업그레이드 = 더 다양한 검사 가능

---

## 11. 탐사 중 위험 요소 / 간단한 전투성 추가

포획만 하면 단조롭기 때문에, 탐사에 위기 요소를 넣는다.
하지만 액션 게임처럼 만드는 건 아님.

### 추천 방향
- 오염 점액 덩어리
- 생체 잔재
- 변이성 위험물
- 정화가 필요한 이상한 액체
- 소형 위협 개체

### 방식
- 손전등으로 식별
- 정화 도구 / 충격 장비 / 직원 지원 활용
- 짧은 충돌
- 전리품 획득 가능

### 전리품 예시
- 오염 샘플
- 부품
- 정화 재료
- 센서 부품
- 연구 데이터

### 주의
- 일반 동물을 사냥하는 게임처럼 만들지 말 것
- 전투는 긴장감과 자원 루프를 위한 보조 시스템

---

## 12. 추적망 접근 기능 강화

현재 추적망 접근이 단순 메뉴면 재미가 약하다.
정보 시스템으로 강화해라.

### 추적망이 할 수 있는 것
- 최근 감지 위치 표시
- 이동 방향 힌트
- 위험 구역 경고
- 발자국 출현 확률 상승
- 특정 개체 행동 패턴 분석
- CCTV 판독 보정
- 도주 방향 예측

업그레이드에 따라 점진적으로 강해져야 하며,
처음부터 정답을 다 알려주면 안 된다.

## 13. 버그 우선 수정

반드시 우선 해결할 것:

1. 보급 버튼을 눌렀는데 보급 화면 대신 다른 곳으로 가는 문제
2. AP 0에서 하루 종료가 안 되는 문제
3. 야간 대응 후 다음 날 AP가 0으로 남는 문제
4. 탐사 버튼/장비 버튼이 먹통처럼 느껴지는 문제
5. 튜토리얼에서 잘못된 화면 이동 유도
6. 저장/불러오기 후 상태 꼬임

이 부분은 실제 테스트까지 수행해라.

## 16. 최종 기대 상태

최종적으로 플레이어는 다음을 경험해야 한다.

- 기지에서 장비와 자원을 준비
- 손전등을 들고 어두운 맵으로 탐사
- 발자국과 흔적으로 동물을 추적
- 이미 확인한 구역은 계속 밝혀져 있고, 개체가 다시 들어오면 실시간으로 보임
- 포획은 직접적인 조작감이 있음
- 탐사 중 오염체나 위험 요소와 짧은 충돌이 있음
- 전리품으로 기지를 강화
- 동물을 격리하고 연구하면서 인간의 흔적을 발견
- EVE와 직원들의 정체가 천천히 드러남
- M-00과 ARKTOPIA의 진실이 후반부로 자연스럽게 이어짐
