# UI_GAMEPLAY_SPEC — 접근성이 좋고 직관적인 상용 게임 느낌

## 첫 30초 사용자 테스트
초면 플레이어가 도움말을 열지 않고 10초 안에 (1) 현재 목표 (2) 위험 동물/시설 (3) 지금 가능한 행동 (4) 하루 종료 위치를 설명할 수 있어야 한다. 툴팁은 보조 수단. 게임성을 텍스트 버튼으로 대체하지 않는다.

## 디자인 토큰
구현 기존 UI 라이브러리 존중. 하나의 테마 변수로 colors, surfaces, text, borders, radii, spacing, shadows, transitions 통합. 이미지 아트의 분홍·라벤더·플럼을 남기되 UI 바탕은 먹빛·짙은 플럼으로 대비 확보. 정보 상태 컬러 4개만: 보통/주의/위험/성공. 같은 의미의 배지는 한 색상. 과한 그라디언트/글로우/테두리 중복 금지. 리치 픽셀 아트는 그래픽 영역에서 살리고 아이콘은 동일 스타일 SVG/lucide 등의 단일 출처 사용.
폰트: 한글 잘 읽히는 본문 14~16px(데스크톱), 모달 본문 15~16px, 메뉴 14~16px, 타이틀 20~28px. 너무 작은 10px 레이블/얇은 저대비 텍스트 금지. 숫자 HUD tabular-nums. 스프라이트 image-rendering: pixelated는 원본 소스가 적절할 때만 적용해 선명도 확보.

## 공통 레이아웃 (데스크톱)
┌ 앱 헤더: DAY | 시간대 | 전력 | 식량·물자 | 동물 생존/격리 | 위험 | [오늘 종료] ┐
│ 좌측 접이식 200~232px 메뉴 │ 중앙 유저 작업 60~75% │ 필요할 때만 우측 상태 250~320px │
│ 대시보드, 동물/격리, CCTV, 탐사·추적, 시설·전력, 직원, 병리·연구, 기록·사진, 설정 │
└ 하단 EVE 알림/실시간 사건 로그 (접고 펼침 가능; 중요한 조작 영역 침범 금지) ┘
모든 탭에 동일한 header/nav/cards/modal/button/spacing. 탭만 바뀌면 주요 제어 위치가 뛰지 않도록. 좌측 메뉴 잠금은 잠금 아이콘과 '언제 열리는지' 암시. 우측 패널은 항상 채우려고 억지 정보 반복하지 말 것. 미니맵은 탐사 화면이 클 때만 하나.

## 홈/대시보드
첫 화면 초반의 핵심: 중앙의 동물원 오버뷰에서 정상/위험 우리와 전력선, 오른쪽의 오늘 최우선 행동 2개. 자원과 위험 우선순위 고정. 오늘의 사건 1개를 선명한 카드로 표시. 직원이 0명이라면 빈 4슬롯을 과하게 강조하지 말고 '아직 합류하지 않음' 정도만 보여주기. 하루 종료 버튼은 실수 방지 확인/핵심 경고만 제공.

## CCTV
3~6개 카메라 썸네일, 주 화면 영상, '어제 기준' 비교 모드, 의심 지점 표시(클릭 전에는 정답 가리기), 1~3회 판정 후 결과. 잘못 클릭하면 재검사 기회 및 자원/신뢰 영향, 반드시 학습 가능한 이유. 영상은 정적인 이미지에 CSS 깜빡임만 붙이는 형태를 넘어 오브젝트/위치/행동 변화가 분명해야 함. 텍스트로 '이상이 있다'라고 쓰는 것으로 끝내지 말고 눈으로 찾게 할 것.

## 탐사/포획
중앙 실제 맵 65~75%, 나머지는 목표/흔적/도구. 맵 셀 상태: 걸을 수 있음, 장애물, 조사 가능, 위험, 미확인, 탈출 경로. 같은 타일 클릭을 무한 반복하게 만들지 않음. 흔적은 갈수록 방향성이 강해지고, 5/10/15 행동별 분명한 보상, 20행동 이내 다음 단계 전환 가능. WASD/화살표 이동, E 조사, F 포획, ESC 메뉴; 모바일은 하단 터치 조이스틱/행동 버튼. 히트박스 넉넉하게, 카메라 전환할 때 길 잃지 않게 함.
포획 미니게임: 매복 위치와 유인 방법 선택 → 동물이 움직이는 동안 타이밍/마우스 드래그 또는 방향 입력으로 포획 → 판정/보상/동물 상태 반영. 동물마다 애니메이션 텔레그래프(도주 전 몸 떨림 등). 단순 일률적인 확률 버튼 금지. 성공하면 save state를 확정한 뒤 시네마틱/이동.

## 격리/검사/연구
개체별 하나의 '운영 카드': 종, 별명/ID, 현재 상태(건강/감염 위험/신경 안정), 먹이/전력 의존, 최근 사건. '검사하기' 버튼을 누르면 검사 종류, 조건, 시간, 자원만 명료하게 제시. M-00 기원 표식은 3막 이전 UI 완전 숨김. 병리·검시실에는 비침습/정밀 신경/사후 검시 3탭, 생존 개체 사후 검시 비활성+이유.
토끼 본부 이송 시 격리실 제거, 잘못된 남은 튜토리얼/우리 표시 버그 필수 수정.

## 직원 화면
최대 4명, 각 역할명·현재 배치·정신력·중요한 상황 대응 효과. 직원 카드 클릭시 깔끔한 고정 중앙 모달: 인물 초상/짧은 성격/현재 상태/행동(대화, 휴식, 지원, 닫기). 미래 수치 감소를 장문으로 쏟아내는 경고창 금지. 과로를 방치하면 반응 지연/실수/다음 날 탈진이 실제로 발생하고, 회복 행동으로 개선될 것. 직원이 아직 도착하지 않았는데 해당 대화나 방문자가 등장하지 않도록.

## 밤 위기 화면
야간 세션 전력 HUD 항상 표시. 중앙 사건·수리 보드/인접 감시, 한쪽에 타이머와 직원 배치, 반대쪽에 경보. 퓨즈 연결은 드래그 스냅, 회로/전력 분배는 시각적 시뮬레이션. 한번에 하나의 주 작업과 하나의 위협이 초기에 등장, 중반 이후 복합화. 실패하면 피해 흔적/사건으로 전환하되 되풀이 게임오버 금지. 키보드/마우스 조작 피드백, 사운드 On/Off.

## Hidden Photo와 시네마틱
사진 목록은 12개 기록 카드 + 복원 상태 + 증거 관계선. 회수/복원 이유가 분명해야 하고, 풀리기 전까지 이미지를 희미하게 처리하되 사진 원본의 주인공 정체를 미리 드러내지 않기. 사진 복원은 마우스로 조각 정렬/스크래치 레이어 조절/파일 대비 복원 등 짧은 상호작용(과도한 그라인드 금지).
시네마틱 전체 16:9, 정사각 화면에 늘이기 금지, object-fit contain, 대사 길이·폰트 크기와 무관한 고정 이미지/자막 영역. 타이핑 속도/텍스트 표시 한 번에/건너뛰기/프롤로그 재보기. 모바일에서 확대·축소가 아닌 올바른 재배치.

## 초보자 접근성 + 피드백
플레이어가 눌렀을 때 '무엇이 바뀌었는가' 즉시 보여주기(상태 HUD 변화, 이펙트, 로그 한 줄). 확정이 필요한 파괴적 선택은 확인. 알림은 동일 위치에 최대 2개. 비활성 버튼마다 이유. 색약 고려: 색뿐 아니라 아이콘·문구 병기. 키보드 접근/ESC/포커스 링/모달 포커스 관리, prefers-reduced-motion, 마우스 히트박스, 모바일 터치 키. 텍스트/상호작용 배경 대비 확보. 여백을 이용해 정보 과밀 방지.

## 화면 크기 검수
데스크톱 1366×768, 1600×900, 1920×1080. 태블릿 1024×768. 모바일 390×844 및 360×800. 공통 네비 접기, 우측 패널은 서랍/탭으로 전환, 하단 액션은 safe-area 고려, 모달 90vw 제한 및 내부 스크롤. 모든 화면 사진/아이콘/카드가 잘리거나 겹치지 않아야 함.

## 플레이어 테스트 목표(권장)
첫 30초 다음 목적/이동법을 스스로 발견, 첫 3분 첫 이상 반응, 첫 10분 실제 위기 대응. 엔딩은 단순 자원 누적이 아니라 플레이 중 했던 보호/희생/본부 협조의 기억이 보상되도록. 성취 배지보다 독특한 사건 피드백 우선.

## 후반 ARK RECALL 진행 화면
진실이 밝혀진 뒤에만 격리/도감에 새 '전 개체 재호출' 탭 해금. 기존에 등록한 모든 고유 animalId별 상태(동물원 격리 중/탈출/본부 이송/사망/미확인), 수집해야 할 생존·기억·기원 정보, 가능한 행동(재검사/재추적/본부 자료 회수/기록 분석)을 표시. 종별 묶음은 UI 편의용일 뿐 진행 판정은 개체별. 진행률은 '필요한 기록 완료/총 등록 개체'로 명확히 표시. 5~10개마다 연구 단서/시설 기능/대화 등 실제 보상, 최종 데이터가 모이면 면역 연구 해금. 레벨이 낮을 때는 자막만 누르는 노가다가 되지 않게 개체별 다른 미션과 짧은 상호작용을 제공.
