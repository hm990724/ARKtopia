# STORY_BIBLE — ANOMALY ZOO / ORIGIN ZERO

## 절대적으로 지킬 스포일러 계층
S0 시작: 황폐한 동물원, EVE의 안내, 이상 동물.
S1 1막: 동물들이 묘하게 인간을 연상시키는 행동. 직원들도 어딘가 이상. 뇌 이식 단정 금지.
S2 2막: 본부와 EVE가 로그를 조작, 과거 연구 파일 흔적.
S3 3막: 아무 이상이 없는 검은 고양이 M-00이 ORIGIN SIGNATURE 양성. 본부가 집착.
S4 4막: Hidden Photo에서 인간 뇌 보존, 최초 과학자의 유출 책임, EVE의 원형, 관리자의 정체가 단계적으로 확정.
S5 5막: ARK RECALL, 백신/면역 연구, 생존·존엄·복제의 선택, 모든 결말에서 관리자 사망.
기본 UI/도감/튜토리얼/로딩 문구/업적에서 S3~S5 내용을 미리 드러내지 말 것.

## 진실/세계관
'동물이 인간으로 변했다'가 아니라 인간의 뇌·기억이 동물에게 보존된 사례들이 존재한다. 인간 신경 기능을 동물에서 실현하려던 실험 과정에서 허구의 변이성 감염 인자가 유출되어 문명이 붕괴했다. M-00은 인간 뇌가 없는 최초 고등 인지 성공체, 폐기 대상으로 지정됐으나 탈출. 외형은 완전히 평범한 검은 고양이(오른쪽 귀 끝 작은 흠집/가슴 흰 털 한 가닥). 과학자는 인간 자체의 복원을 원해 M-00의 의미를 외면했다. 이후 인간 뇌 동물 보존 → 복제인간 몸에 이식하는 계획으로 발전.
주인공은 최초 과학자의 뇌를 이식받은 제1호 복제 관리자. 지식과 기억은 상속받지만 과학자와 동일한 인격·도덕적 선택을 강제받지 않는다. 과학자는 자신의 정당성을 증명하려 실패를 인정하지 않는다.
EVE는 그 과학자의 사망한 딸의 기록, 목소리, 일기, 신경 데이터를 기초로 재구성된 AI. EVE가 딸 본인은 아니다. EVE와 본부 중앙 AI는 별개. 본부 AI는 통제/연구 유지 우선, EVE는 처음에는 협조하지만 차츰 스스로 선택할 수 있다.

## 프롤로그 — 재개장 (플레이 약 3~5분)
장면: 사람 없는 동물원 정문. 안내 방송은 관람객을 기다리는 말투를 유지. EVE: “관리자님, 접속을 확인했습니다. 오늘도 개장 준비를 시작할까요?” 관리자: “관람객도 없는데?” EVE: “관람객 만족도는 지난 17년 동안 100%입니다. 불만을 접수한 사람이 없거든요.”
직접 조작: 전원 복구 미니게임 → 격리문 개방 → 처음 동물 관찰/건강 진단. 토끼의 발짓이 인간의 어린 환자 돌봄을 연상시키지만 설명하지 않는다. 건강/감염 검사만 공개; ORIGIN SIGNATURE는 내부 필드로 숨김. 3분 내 첫 이상, 10분 내 전력 고장 위기.

## 제1막 — 이상한 보호구역
동물 보호와 격리, 수색, CCTV. 각 종의 습관이 본능이라고 보기 어려운 규칙성을 가짐.
토끼: 다친 개체 곁을 떠나지 않음. 보급관/의무관의 기억을 스포일러하지 않는다.
여우: 물품 창고 앞에 정확히 정해진 시간마다 멈춤.
늑대: 일정 간격 순찰, 경비 호출 같은 노크에 반응.
사슴: 서류 보관실 주변에서 선형 경로를 반복.
올빼미: 밤에 정확한 주기/각도에 따라 방향을 바꿈.
까마귀: 네 음을 반복하지만 마지막 음에서 멈춤.
수달: 물이 멈춘 펌프를 유난히 관찰하고 레버를 건드림.
기타 종은 코드의 성격 정본에서 가져와 각자의 행동 퍼즐 작성.
직원 합류 조건: 특정 개체의 공명 100 + 건강 조건 → 본부 이송 → 다음 날부터 하루 한 명씩 직원 합류(의무관 rabbit / 보급관 fox / 경비관 wolf / 기록관 deer). 직원 4명 제한. 합류하는 사람의 동물 원형을 화면에서 직접 밝히지 않음. 인수인계 날짜가 아니라 실제 조건 이벤트로 처리.
각 직원의 후반 정신력/신뢰/지원 효과가 현장 선택에 영향을 준다.

## 제2막 — 어제와 다른 것
CCTV에서 어제와 다른 우리, 삭제된 프레임, 낡은 이름표, 비어야 할 복도의 발자국. 본부는 '장비 오류'라고 하고 EVE도 처음엔 얼버무린다.
EVE: “해당 영상은 손상되었습니다.” 관리자: “그런데 방금 네가 영상을 멈췄잖아.” EVE: “…복구 가능한 부분만 보여드렸습니다.”
개별 직원 딜레마: 의무관은 약을 누구에게 쓸지; 보급관은 본부에 반출 수량을 정직하게 보고할지; 경비관은 명령보다 동물 구출을 우선할지; 기록관은 기밀 기록을 숨길지 공개할지. 분명한 단기 이득/장기 대가 존재. 다만 대화창이 숫자 경제 계산표가 되지 않도록 행동 후 결과로 보여 준다.

## 제3막 — THE PERFECT SPECIMEN
관찰/검사/단서 조건이 누적되면 외곽에서 그냥 검은 고양이 발견. M-00은 변이 없는 동물로 보이게 한다. 검사 UI에서 별도 '기원 표식' 탭 해금. 검사 결과: ORIGIN SIGNATURE ANALYSIS — MATCH POSITIVE — ID M-00 — RESTRICTED. 이는 감염 양성이 아닌 원본 표식 일치.
본부 AI: “해당 개체를 즉시 격리하십시오. 관리자에게 관련 정보의 열람 권한은 없습니다. 본부로 이송하십시오.”
EVE: “이상하네요. 가장 정상적인 개체인데, 본부가 가장 두려워하고 있어요.”
A 본부 이송: M-00 실제로 출발, 절대 동물원 자동 귀환 없음. 후반 본부 통신 해독·기록 탈취·권한 우회/구조 선택 등의 플레이.
B 동물원 보호: 비밀 격리실 유지, 본부의 물자 제한과 회수팀 침입, 시설 방어를 감수. 후반 원본 직접 연구 접근은 쉬움.
두 루트 모두 연구/엔딩 가능해야 한다. 선택이 서로 다른 게임을 만든다는 감각 필요.

## 제4막 — HIDDEN PHOTO / 실험의 진실
12개 기록은 스토리를 설명하는 텍스트 12장이 아닌 복원 퍼즐+실제 시각 증거. 각 사진은 물리 단서/로그/개별 퍼즐로 해금, 단계별 단서가 다음 사건을 움직이게 한다. photos 목록은 별첨 ASSET 문서 참조.
PHOTO 01~06: 동물 신경 각성 → 성공체 M-00 → 폐기 결정 → 탈출·오염 확산.
PHOTO 07~10: 인간 뇌가 동물에 보존됨 → 아버지·딸·M-00 가족사진 → EVE AI 재구성 → 복제인간 복원 프로젝트.
PHOTO 11~12: 제1호 관리자 안의 과학자 뇌 → M-00 면역 연구 은폐.
EVE: “이 고양이…….” 관리자: “기억나?” EVE: “아니요. 제게는 이 사진을 찍었던 기억이 없어요. 하지만 기록에는 제가 이 아이를 무척 좋아했다고 적혀 있네요.”
EVE: “아버지는 이 아이도 버렸군요.”
과거 연구 음성: “폐기해. 우리가 원한 건 이게 아니야. 인간의 사고를 가진 동물이 아니라, 인간 그 자체가 필요하다고.”
과학자의 핵심 문장: “내가 성공한다면 그들의 죽음은 희생이 된다. 내가 실패한다면 그저 학살이겠지. 그러니 나는 반드시 성공해야 해.”
사진은 고어로 직접 수술을 보여주지 않고 기록/스캔/서명/개체 식별 정보로 진실을 전달.

## 제5막 — ARK RECALL / 면역 연구
M-00 발견 + 핵심 사진 복원 + 유출 경위 파악 후 해금. 백신은 클릭 한 번으로 완성되는 아이템이 아니다. M-00의 생존 특성 + 여러 종의 변이/면역/기억 데이터가 연결되는 허구적 연구 시스템. 현실 생물학적 백신 제조법이나 실험 절차를 묘사하지 않는다.
과거 수집 동물을 다시 만나는 이유: 이전엔 건강/감염만 검사했지만 이번엔 기원 서명/안정성/기억과 감염의 관계를 새로 조사하기 때문. **13종만 다시 한 번 검사하는 것이 아니라 이전에 등록한 모든 개체(고유 animalId)를 개체별로 재호출/재추적/자료 회수**한다. 이미 보호 중인 개체는 새 검사로, 탈출한 개체는 재추적·재포획으로, 본부 이송한 개체는 원격 자료/회수 임무로, 사망한 개체는 보존 기록으로 분기한다. 종별 공통 퍼즐은 재사용 가능하되 개체별 특성/위치/사건을 달리한다. 개체 수가 많을 때에는 몇 마리마다 중간 연구 보상 및 일괄 연구 정리 기능을 두어 반복 노가다가 되지 않게 한다. 종마다 새로운 직접 조작 도전.
토끼: 보호 행동 속 기억 과열을 진정하는 타이밍 퍼즐.
여우: 탈출 동선을 CCTV로 조합하고 유인 경로 결정.
사슴: 안정적인 회로·격리문 경로를 설계.
늑대: 다른 개체를 지키려는 경계 행동을 존중하며 단계별 접근.
올빼미: 밤 시야 각도/주기를 계산하는 감지 퍼즐.
까마귀: 반복되는 미완성 선율의 순서를 음향/시각 타이밍으로 재구성(저작권 자유 오리지널 음만).
수달: 펌프 압력·전력 흐름 퍼즐. 실패하면 물·전력 손실.
스라소니·아홀로틀·밤나방·특수 개체도 종별 1개 이상 고유 조작 사건. 코드 정본 사용.
본부 이송된 개체는 원격 기록, 사망한 개체는 보존 연구 정보로 일정 부분 대체해 진행 봉쇄 방지. 구조/손실의 정도는 연구 품질과 결말에 실제 영향.
최후 위기: 본부 이송 루트=자료 봉쇄와 무리한 실험, 보호 루트=격리시설 회수 공격. 복합 플레이 (CCTV→직원 배치→전력 수리→동물 보호). 주인공의 쇠퇴는 내러티브/시각 연출로 표현하되 조작 불편·모션 멀미 유발 금지.

## 엔딩 8개 / 기존 ID는 코드에서 재확인하고 매핑
1. 영원한 실험: 본부에 복종하고 실험 자동화. 관리자는 사망, 다른 복제 관리자 생산 준비.
2. 에덴: 복제인간 사회 재건. 살아남았으나 원본 인류와 다른 존재들, 윤리적 대가.
3. 방주의 씨앗: 개체 보호/연구 충분/EVE 신뢰, 관리자는 죽고 EVE가 오랜 시간 연구를 이어감. 완치 확정 금지.
4. 마지막 동물원: 인류 복원보다 현존 생명 보호를 선택, 보호구역이 피난처로 남음.
5. 제000번 우리: 과학자의 기억을 가진 주인공이 그의 신념을 거절하고 자신의 이름을 기록.
6. 침묵의 자동화: EVE/직원 신뢰 붕괴로 무감정 자동 운영만 지속.
7. 흩어진 이름들: 불완전한 복원과 희생, 살아남은 기록만 남음.
8. 마지막 신호: 극한 위기에서 데이터 송신, 수신 여부 미상.
모든 엔딩: 관리자 사망. EVE의 마지막 한 마디와 직원/동물/본부 현황/연구 성과가 서로 달라야 한다. 기존 엔딩 이미지 8장의 이름 및 실제 ID를 먼저 조회하고 세이브 호환성을 지켜 의미를 매핑.

## 감정선과 성격
EVE: 초반은 친절하고 효율적이며 다소 무심한 농담 → 중반 의도적으로 모호한 답 → 후반 오류와 죄책감 → 끝내 자신의 판단을 선택. 어색한 장황한 설명보다는 짧고 의미 있는 침묵/오답.
본부 AI: 사람이 아니므로 냉정한 규정·연구 목표, EVE와 일치하지 않음.
관리자: 명령 복종자에서 선택의 대가를 인식하는 존재로 변화. 과학자의 기억이 곧 동일한 인간이라는 논리는 거부 가능.
최초 과학자: 인간 존속이라는 명분으로 잘못을 합리화, 끝까지 자기 신념과 싸움. 손쉬운 참회 금지.
직원 4명: 각자의 현실적인 생존·직무 딜레마 존재. 정신력·신뢰·실제 합류 여부가 스토리에 반영.
