M-00이 극후반 발견되고 기원 표식 검사가 POSITIVE로 나오지만 이는 감염 양성이 아니라 기원 표식 일치다. 이후 Hidden Photo 12개의 증거를 모아 본부의 은폐, 유출 사고, 인간 뇌 이식, 과학자의 딸을 기반으로 재구성된 AI EVE, 최초 과학자의 뇌를 가진 복제 관리자 자신을 발견한다. 백신/면역 프로젝트는 M-00 발견 즉시 완성되는 것이 아니라, 후반 ARK RECALL에서 기존 동물들의 새로운 정보를 다시 수집해야 진행된다. 관리자 자신은 모든 엔딩에서 죽지만, 남기는 결과는 분기된다.

1일 권장 플레이 길이 8~12분. 우연 이벤트 반복 말고 이전 선택, 직원 피로, 개체 상태, 전력·물자·EVE 신뢰와 연결된 사건 1개 이상. 공통 관찰 20회 내 핵심 발견 보장, 5/10/15회 중간 보상. 플레이 실패는 손실/후속 사건을 남기되 불합리한 막힘이나 즉시 게임오버 남발 금지.

[UI/UX 공통 계약 — 디자이너처럼 직접 구현]
하나의 디자인 토큰: 연분홍·라벤더·플럼 계열은 아트 자산의 특징으로 살리고, 배경 UI는 어둡고 차분한 차콜/플럼/먹색. 강조색은 상태에만 쓰고 과한 네온 남발 금지. 카드/제목/본문/버튼/아이콘의 크기, 행간, 그림자, 보더, radius, spacing를 토큰화. 버튼 위치 고정. 모든 화면에 동일한 기본 배치: 좌측 내비게이션(접이식), 상단 자원/HUD, 중앙 주 조작 화면, 우측 맥락 패널(필요할 때만), 하단 EVE/로그/툴팁 영역. 중앙 플레이 필드는 최우선. 1366×768/1600×900/1920×1080 및 좁은 모바일 가로/세로에서 터치 대체 조작 제공, 잘림 및 스크롤 지옥 금지.
첫 플레이에 인게임 튜토리얼은 한 번에 한 가지 조작만 안내. 중요한 목표는 좌상단 고정, 위협 경보는 상단에서 구분, 완료 결과는 중앙 시각 피드백 + 짧은 텍스트. 정보 밀도보다 우선순위, 시선 흐름, 크기·대비·여백 정리. hover만으로 기능 설명하지 말고 클릭·키보드·터치 지원. UI 명칭 한국어 통일. 누르면 반응 없는 버튼 금지.
모달: 직원 카드 클릭 시 중앙 모달에 초상/직무/정신력/짧은 서사/대화/지원/닫기. 우측 전체 화면 확장형 장황한 설명 패널 금지. 플레이에 영향을 주는 선택은 짧은 설명과 실행 결과 명시하되 미래 숫자 패널티를 과도하게 미리 스포일러하지 않는다. 다른 모달도 치수·ESC 닫기·포커스·배경 스크롤 잠금 일관.
시네마틱: 16:9 전체화면(레터박스), 그림 object-fit contain, 하단 고정 자막 영역, 이전/다음/건너뛰기, 자연스러운 타입 효과 및 속도 설정. 텍스트 길이에 따라 배경 이미지 크기 요동 금지. 일러스트를 저퀄 CSS 조각으로 대체하지 않음.
