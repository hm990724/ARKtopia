# ECHO WARD · 잔향보존구역 v34

2089년 멸망 이후의 보존구역을 배경으로 한 **Next.js 15 / React 19 / TypeScript** 선택형 생존·동물 보존 게임입니다.

## v34의 핵심: 발자국이 멈춘 곳

- 탐사 이동: 7×5 폐허 맵에서 흔적·물자·생체 신호 조사.
- 포획: **8×8 완전 은신 격자**. 개체의 현재 위치는 표시하지 않고, 이전 턴 발자국과 그 주변 8칸의 풀이 흔들리는 효과만 보여줌.
- 여우는 매 턴 가짜 발자국 1개 추가. 토끼는 2칸 도약하고 먹이에 한 칸씩 접근.
- 모든 개체는 서로 다른 이동 특성·실패 페널티·자극 학습 규칙 보유. 세 가지 행동 힌트는 각각 행동 1회를 지불하고 해독.
- 수풀을 **정확히 찍어야** 포획. 먹이·소리·빛·차단막은 동물의 이동을 변경할 뿐 자동 포획하지 않음.
- 첫 토끼는 튜토리얼로 무조건 등장·구조 가능, 이후 일반 개체는 정해진 행동 횟수 초과 시 도주.
- 기존 격리실, 기억 공명, 본부 이송, 변이체 관리, CCTV 탈출·추적, 엔딩 유지.

## 설치와 실행

```bash
npm install
npm run test:v34
npm run test:v32
npm run typecheck
npm run build
npm run dev
```

게임 주소: http://localhost:3000

**중요:** `public/assets/`는 포함하지 않았습니다. 사용자가 확정한 기존 이미지 경로를 그대로 참조하므로, 기존 `public/assets` 폴더를 유지해 주세요. 이 폴더를 삭제하거나 ZIP으로 교체하면 이미지가 표시되지 않습니다.

코드에서 불러오는 한국어 폰트는 Google Fonts의 **Noto Sans KR / Noto Serif KR**, 상업적 사용이 허용되는 SIL OFL 라이선스입니다. 폰트 바이너리를 재배포하지 않습니다.

변경 내역, 검증 상태, 규칙 상세는 [V34_RELEASE.md](V34_RELEASE.md)를 참조하세요.
