# 잔향보존구역 — ECHO WARD (v21)

기존 ARK v20 프로젝트를 기반으로 탐사 가독성 및 게임 브랜드를 개선했습니다. 저장 로컬스토리지 키는 호환성을 위해 유지합니다.

## 실행

```bash
npm install
npm run typecheck
npm run build
npm run dev
```

## UI 변경

- 탐사 준비: 지역 카드 6개와 선택 구역 브리핑, 자원·장비 편성 패널
- 탐사 진행: 왼쪽에 현장 이미지 및 계측 값, 오른쪽에 큰 사건 본문과 대응 버튼
- 사건과 버튼의 한글 본문 확대, 충분한 행간 및 줄바꿈
- 제목: 잔향보존구역 / ECHO WARD
- 기존 동물·CCTV·저장·관리 시스템 유지
