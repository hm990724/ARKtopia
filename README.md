# 마지막 우리 / THE LAST ENCLOSURE — v10

실제 조작 가능한 선택형 서바이벌 동물원 게임. Next.js 15 + TypeScript + React 19.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000. Node.js 20 이상 권장.

## v10 새 시스템

- **시작 분기:** 4가지 기억 × 4가지 시작 장소. 시작 자원 및 캐릭터 효과가 달라집니다.
- **클릭형 현장 탐사:** 6개 구역, 구역별 해금 시기·위험·보상·행동력·전력 비용. 맵 이동 대신 3단계 접근/강행/장비 사용/철수 선택. 위험도에 따라 자원·동물 발견·피해 판정.
- **주 전염 위험:** 방사능 중심을 바이러스 감염 위험으로 변경. 감염/위협/시설 안정성/체력이 연결됩니다.
- **전력의 의미:** 자동 원격 탐사·EVE 분석·야간 경계는 전력을 소모. 정전 시 손전등을 장착하면 제한된 수동 탐사를 시도할 수 있습니다. 전력 충전은 부품과 행동력이 필요합니다.
- **휴식/수동 수색:** 체력·정신력 회복 또는 손전등 전지 소비로 기본 물자 수급. 위험을 미루면 다음 사건 확률에 영향을 줍니다.
- **격리 동물 개별 관리:** 바이탈(HP·스트레스·유대·기억 공명·오염), 급식·치료·교감·관찰, 개체를 구조하면 격리실에 배치.
- **기억 추출:** 이동하는 바를 정확한 타이밍에 고정하는 미니게임. 완만/강제 방식에 따라 추출과 피해 차등.
- **EVE 대화:** 문장별 수동 진행. 클릭하여 먼저 문장을 완성하거나 다음 발화로 이동. 발화자에 따라 EVE/주인공 초상화 전환.
- **특별 사건:** 감염도, 시설 불안정, 위협도, 보유 개체, 조사 기록 등 조건에 따른 발생 확률. 직전 사건은 기록 탭에서 확인. 사건 처리 후 자원·상태 변화.
- **구조 성공·실패:** 전용 일러스트 결과 화면. 구조 판정 전까지 격리실로 동물이 즉시 추가되지 않습니다.
- **야간 전력 운영:** 별도 화면에서 가용 전력/소모량/예상 잔량 확인 후 작전을 확정.
- **후반 복선:** 인류의 멸망과 의식 보존, 주인공의 변이체 정체는 시간·기억/단서 조건을 충족한 뒤에만 드러납니다.
- **반응형:** PC 화면의 상단/사이드/메인/하단 분리, 작은 화면의 자체 스크롤과 모달 높이 제한.
- 자동 저장: `localStorage` (`last-enclosure-ark-v10`). 이전 저장 파일을 가져오는 기능은 포함하지 않으며 v10의 신규 시작을 권장합니다.

## 게임 플레이 흐름

처음 기억/위치 선택 → 중앙에서 상태 확인 → 탐사 지역 클릭 → 장비 선택 → 현장 3단계 판단 → 동물 구조/회수 → 격리실 관리 → 전력 보충/휴식/기억 추출 → 야간 전력 작전 → 조건에 따라 특별 사건 → 엔딩.

## 주의

- 제공 게임은 단일 브라우저 프로토타입이며 실제 대규모 상용 게임의 콘텐츠 분량/게임 밸런스를 보장하지 않습니다.
- 캐릭터, 배경 및 구조 결과 이미지는 `public/art` 폴더에 포함. 진짜 프레임별 동물 애니메이션은 포함되지 않으며 CSS 이동/전환 애니메이션을 사용합니다.
- 확률 사건은 플레이마다 달라지며 결과 저장은 브라우저 단위입니다.

- 실제 브라우저 빌드는 의존성 설치 시 환경에 따라 추가 검증 필요.

- `public/assets/backgrounds/`: 기존 동물원/연구소/사진 배경 7종. `ASSET_MANIFEST.json`은 이미지 자산 목록의 공식 파일명입니다.
- **공룡 콘텐츠 제거:** `dino`/`raptor` 이미지 제거, 수집·탐사 등장 풀에서 공룡 제외. 기존 저장의 공룡은 불러올 때 제외됩니다.
- **총 13종:** 보존 동물 10종, 변이·합성 개체 3종(`mutant`, `chimera`, `specter`).
- **행동 강령 공명:** 모든 개체는 독립적인 3단계 행동 프로토콜(`src/lib/protocols.ts`)이 있습니다. 동물 관찰 1회, 유대 20+, 스트레스 78 이하, HP 35+, 행동력 2, 전력 7 이상을 만족해야 지식을 얻을 수 있습니다. 잘못된 강령을 고르면 지식 없이 개체가 스트레스를 받습니다. 비침습/강제 모드의 보상과 위험이 다릅니다.
- **생체 합성 연구:** 연구 화면에서 공여 개체 2종을 선택합니다. 지식 25 / 전력 18 / 부품 2 / 행동력 2 / 빈 격리실이 필요합니다. 성공 시 두 개체의 특성에 따라 새 변이체 등장, 실패 시 시설과 개체에 부작용이 발생합니다. 공여 동물은 죽거나 소비되지 않습니다.
- **검사:** `node scripts/test-v13.cjs`는 개체별 행동 강령, 합성 성공·실패, 동물 관리 전제 조건, 기존 저장 호환을 검사합니다. `node scripts/test-v10.cjs`는 기존 게임 진행 시뮬레이션을 실행합니다.

※ 이미지 폴더에는 현재 옛 이미지를 복사한 **임시 교체용 파일**이 있습니다. 새 도트 디자인이 이미 모두 완성된 것은 아닙니다.

## v15 — 최소 합성 구성 / 엔딩 이미지 슬롯

- 일반 동물 10종 + 변이체 `mutant` 1종 + 합성체 `chimera` 1종만 유지합니다. 과거 `specter` 데이터 및 구역 출현/합성 결과를 제거했습니다.
- 합성 결과는 접합체 미라 한 종만 가능합니다. 이미 살아 있는 접합체가 있으면 재합성할 수 없습니다. 기본 동물 2종만 공여자로 사용합니다.

## v16: 인간 음성 발현 연출
- 바이러스 생존자들이 사망하기 전 남긴 의식 기록이 동물 신경계에 보존되어 있다는 설정을 사용합니다.
- 평소 동물은 울음소리와 행동으로 반응하며, 기억 공명과 정신적 불안정성이 누적되면 인간의 첫 발화가 발생합니다.
- 어두워지는 6단계 연출: 이상 신호 → 동물 울음 → 인간의 첫 발화 → 두 번째 발화 → EVE 분석 → 관리자 반응.
- 12종 각각 서로 다른 과거 성격·나이·직업을 반영합니다. 동물의 본명/직업은 이벤트 이전에 UI에 표시하지 않습니다.
- 발현 후 개체의 `awakened` 상태를 저장하며, 격리실에서 `인간 음성 기록 재생`으로 장면을 다시 볼 수 있습니다.
- 토끼와 여우는 기존의 `_uncanny.png` / `_mutant.png`를 사용하며, 나머지 개체는 기존 이미지를 재사용합니다. 추가 이미지 없이도 재생됩니다.
- 발현은 기억 복원+스트레스/오염을 기준으로 발생합니다. 돌봄으로 발현 전의 위험을 낮출 수 있지만, 첫 발화 후의 기억은 삭제되지 않습니다.

- 6개 지역마다 3개씩 총 18개의 현장 상황을 구성했습니다. 각 상황의 단서에 따라 안전 접근·강행·장비 사용의 위험 보정이 다릅니다.
- 사이드바·대화·탐사 버튼·모달의 화면 크기별 CSS 개선.
