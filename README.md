# 마지막 우리 — ARK Survival (v9)

Next.js 15 / React 19 / TypeScript 기반 싱글 플레이 포스트 아포칼립스 선택형 생존 게임.

## 실행

```bash
npm install
npm run dev
```

`http://localhost:3000` 접속. Node.js 20+ 권장.

## 이번 버전의 실제 플레이 요소

- 4가지 출발 기억 × 4가지 시작 지역으로 출발점 변화
- 하루 행동력 4. 돌봄/치료/관찰/시설 수리/탐사/기억 추출의 비용 분리
- 7×5 직접 이동 탐사 맵: 방향키/WASD 또는 화면 방향 버튼으로 이동; 장애물, 오염, 구조 지점
- 구조: 발견 → 행동 선택(구조/현장 치료/이탈) → 3단계 연출 → 확률 판정 → 격리실 배정
- 격리실: 동물별 체력, 스트레스, 유대, 기억 공명, 오염, 방 배정; 먹이·치료 물자 소모
- 기억 추출: 움직이는 커서를 표적 구간에 맞추는 타이밍 게임; 완만/강제 추출, 위험과 지식 보상
- 야간 경계: 전력 기반 방어/대피/스캔 3종 선택 및 피해 판정; 누적된 위험도에 따라 특별 사건 발생
- 보존 크레딧: 보급 물자와 격리실 구매, 시설 정비
- 주인공 바이탈, 피폭 누적, EVE 내구도, 동물 사망, 로그, 점진적 진실 개방
- 최후의 보존 결정 3개(인류 재생 / 생명 해방 / EVE와 보존)와 지식/신뢰/생명/EVE/진실 조건별 엔딩, 자동 저장(localStorage)
- 이전 버전의 픽셀아트 에셋 재사용: 캐릭터, EVE, 동물 및 환경 PNG

## 게임 진행

1. 시작 기억/위치 선택 후 구조 대상을 찾기 위해 **탐사** 탭 선택
2. 탐사 출동(AP 2 소모) 후 맵 조작 → 빛나는 조사 지점에서 동물 발견
3. 구조를 선택하면 확률 판정과 운송 연출, 수용 가능한 경우 격리실 자동 배정
4. **격리실** 탭에서 동물 클릭 후 치료, 급식, 교감, 행동 관찰
5. **연구** 탭에서 기억 동기화(행동력 2), 동물의 상태와 성공 타이밍에 따라 지식 획득
6. **보급** 탭에서 크레딧으로 자원 구매/시설 수리
7. 밤을 맞이하면 습격 대응 선택, 이후 동물 먹이 소비/상태 변화/날짜 증가
8. 진실은 초반에 직접 노출되지 않으며 지식/추출/날짜 조건에 따라 후반 복원

## 설계 관련 유의사항

이 게임은 오프라인 클라이언트 게임이며 서버 DB/멀티플레이가 없습니다. 상호작용/선택은 실제 상태를 변경하지만 탐사 지역은 절차적으로 생성된 대형 월드가 아니라 7×5 프로토타입입니다. 음악은 포함되지 않았고, 간단한 Web Audio 효과음만 옵션으로 제공합니다. 원본 픽셀 PNG 파일은 `public/art/`에 있습니다.

## v9 개선 내용
- 이동마다 현장 노출량·방호 장비·탐사 배터리 소모: 장시간 체류와 위험 지역 진입은 체력/정신/오염에 추가 영향. 안전 철수 버튼 제공.
- 야간 사건 확률은 누적 오염, 전력 부족, 구조 개체 수, 사건 누적 위험에 따라 계산하며, 결과와 이벤트 종류가 기록에 남음. 3일 고정 습격은 제거.
- 야간 화면에 전력 계획표(가용·예약·잔여)와 예상 위험도를 상시 표시. 비용 초과 시 확정 버튼 비활성화.
- EVE/주인공 대사는 문장 단위로 표시되고 텍스트가 점진적으로 드러남. '문장 펼치기/다음 대사/대화 종료' 버튼 추가.
- 구조는 3단계 작전 후 성공/실패 결과 화면을 별도 제작한 `public/art/rescue-success.jpg`, `rescue-failure.jpg`로 표시; 확인 전까지 다음 조작 차단.
- 모달 최대 높이/스크롤, 주요 화면 뷰포트 높이/반응형 규칙 수정.
- 기존 v7/v8 저장 데이터 로딩 및 신규 v9 저장 변환 지원.

**제약:** 브라우저 패키지를 설치할 수 없는 환경(EAI_AGAIN) 때문에 실제 Next 빌드/시각적 브라우저 검증은 수행하지 못했습니다. TypeScript 파서 구문 검사와 게임 진행 자동 시뮬레이션으로 검증했습니다. 탐사 지도는 여전히 7×5 그리드 기반입니다.
