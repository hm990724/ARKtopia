## 공통 프롬프트
고밀도 시네마틱 2D 픽셀아트, 폐쇄된 미래 동물원의 생물학적 공포, 검보라·회색·먹색 중심, 제한적인 시안 조명과 붉은 경고등, 선명한 픽셀 경계, 일관된 환경 디자인. 인물·동물·글자·숫자·로고·HUD·버튼·워터마크 없음. 한 장의 독립 이미지, 콜라주 금지.

각 장면 프롬프트에 공통 프롬프트와 규격을 덧붙여 생성. 포자는 투명 배경 전용. 포획/구조/전투/CCTV의 동물과 효과는 코드가 합성한다. 전투는 regions 6장 공용, 긴급 작업은 코드 UI, 지면은 기존 field 텍스처. 옛 73/79장 가이드는 폐기.

## public/assets/gameplay/regions/ — 6장 (1600×900 PNG)

### garden.png — 외곽 숲

### conservatory.png — 폐쇄 온실
깨진 유리 천장과 감염된 식물, 덩굴, 주황색 오염 흔적. 전경은 좌우 캐릭터가 들어가는 평평한 빈 바닥.

### rail.png — 폐역 승강장
정차한 낡은 열차, 선로와 승강장, 푸른 비상등. 전경에 넓은 빈 승강장 바닥.

### archive.png — 관측소 기록실
고장 난 컴퓨터와 기록 선반, 관측 장비와 시안 전원등. 전경의 빈 통로를 좌우 전투 공간으로 확보.

### vault.png — 밀폐 연구동
생체 보존 캡슐과 밀폐문, 배관, 붉은 비상등. 좌우 인물이 배치될 넓은 빈 금속 바닥.

### tunnels.png — 지하 통로
어두운 지하 콘크리트 터널, 배관과 케이블, 안개와 희미한 비상등. 수평에 가까운 넓은 전경 바닥.
