# ARKtopia 게임플레이 이미지 제작 가이드

기준: 2026-11-24. 아래는 실제 코드에 연결한 경로다. 파일이 없으면 기존 스프라이트 또는 CSS 대체 화면이 유지된다. 생성 원화는 포함하지 않는다.

## 통일된 아트 방향
- 고밀도 시네마틱 픽셀아트, 네오누아르 생물학적 공포, 검보라/회색/먹색, 시안 전원등과 제한적인 붉은 경고등. 픽셀 경계가 선명하며 실사/수채화/3D 렌더 느낌 금지.
- 배경과 개체를 분리한다. 글자, REC, 시간, 격자, HUD, 버튼, 성공 문구는 코드가 표시한다. 원화에 넣지 않는다.
- 관리자: 검보라 머리, 분홍 X 고글, 고양이 헤드폰, 검은 테크웨어. EVE: 은백색 장발, 시안 헤드셋, 홀로그램. 기존 동물·직원 디자인과 일치시킬 것.
- Uncanny는 자연 개체 중심, 의복/장비 금지. Mutant만 직업 흔적과 변이를 표현. M-00과 특수 MUTANT 혼동 금지.
- 배경 WebP는 품질 85~92 권장, 대략 150~600KB 목표(고밀도 그림은 예외). 투명 스프라이트 PNG, 원본 작업 파일은 public 밖에 보관. 정확한 소문자 파일명 사용.
- 모든 파일은 하나의 독립 이미지. 콜라주/스프라이트 시트 금지(기존 ranger_walk 시트만 예외). 크롭되는 카드에서는 중요 요소를 중앙에 둔다.

## 우선 제작 순서
1. start 3 + cctv 6 + containment 4 + regions 6 = 19장.
2. recovery/staging 1 + results 9 + combat 6 + operations 5 = 21장. 공통 배경 총 40장.
3. terrain 12 + effects 1 = 선택적 게임용 텍스처/이펙트 13장.
4. capture 13 + recovery 개체별 13 = 선택적 전용 시네마틱 26장. 먼저 토끼, 여우, 사슴, 늑대부터.
총 79개 슬롯(40 공통 배경 + 13 텍스처/효과 + 26 개체별 CG). 모두 필수는 아니다.

기존 파일명 유지. 새 gameplay/ 폴더와 역할이 다르다. 기존 배경을 CCTV·시작 카드·격리실로 돌려 쓰지 않는다.

- public/assets/field/ground.png, world_ground.png: 기존 탐사/포획 지도 바닥 대체 텍스처. 512×512 PNG 권장. 새 terrain 파일 미등록 시 유지된다.
