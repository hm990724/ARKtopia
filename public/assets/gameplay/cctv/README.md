# ARKtopia / CCTV

## cctv/
1280×720 WebP / 16:9 / 높은 벽 모서리 고정 시점. 인물·동물·REC·시간·격자·UI 없음. 모든 격리실은 공용 containment.webp 한 장과 실제 개체 스프라이트를 합성. 방 번호/채널/경보는 코드가 표시.

| 파일명 | 용도 | 이미지 구도 |
|---|---|---|
| `cam-01.webp` | 외곽 출입구 | 높은 벽 모서리, 출입문과 바닥 동선 |
| `containment.webp` | 모든 격리실 CCTV | 단일 보호 우리 내부, 중앙/하단의 넓은 빈 바닥, 잠금 장치·급수기·조명. 고정 번호와 동물 없음 |
| `cam-04.webp` | 연구동 | 관측 데스크와 연구 장비, 빈 실험 공간 |

격리실 수에 따라 채널이 자동 추가된다. 기존 세이브의 수용량을 유지한다.
