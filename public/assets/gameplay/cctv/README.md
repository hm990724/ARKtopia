## 공통 프롬프트
고밀도 시네마틱 2D 픽셀아트, 폐쇄된 미래 동물원의 생물학적 공포, 검보라·회색·먹색 중심, 제한적인 시안 조명과 붉은 경고등, 선명한 픽셀 경계, 일관된 환경 디자인. 인물·동물·글자·숫자·로고·HUD·버튼·워터마크 없음. 한 장의 독립 이미지, 콜라주 금지.

각 장면 프롬프트에 공통 프롬프트와 규격을 덧붙여 생성. 포자는 투명 배경 전용. 포획/구조/전투/CCTV의 동물과 효과는 코드가 합성한다. 전투는 regions 6장 공용, 긴급 작업은 코드 UI, 지면은 기존 field 텍스처. 옛 73/79장 가이드는 폐기.
