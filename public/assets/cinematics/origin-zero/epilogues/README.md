# ORIGIN ZERO 후일담 11장

1600×900 PNG, 16:9. 기존 SCN 시네마틱과 동일한 고밀도 2D 시네마틱 픽셀아트, 검보라/회색과 시안 조명, 인물 외형 일관성. 관리자: 검보라 머리, 분홍 X 고글, 고양이 헤드폰, 검정 테크웨어. EVE: 은백색 장발, 시안 헤드셋, 홀로그램. UI/워터마크/글자 없음. 사후 장면에서 살아 있는 기존 관리자 등장 금지. 생존 여부가 가변적인 직원이나 동물을 고정 등장시키지 않는다.

### END_09_experiment_successor.png
다음 관리자 — 새로운 복제 신체가 기동되는 차가운 연구실. 낡은 X 고글과 이전 관리자의 연구 기록이 놓여 있음. 이전 관리자의 부활로 표현하지 않는다.

### END_10_eden_memory_cost.png
기억의 대가 — 새 정착지의 아침, 복원된 사람들이 서로 다른 삶을 시작하는 장면. 희망과 정체성의 낯섦.

### END_11_seeds_long_research.png
오랜 연구 — 관리자 사망 이후 혼자 연구실을 지키는 EVE, 비침습 연구 장비, 빈 의자, 오랜 시간의 흔적. 치료법이 완성되었다고 표현하지 않는다.

### END_12_zoo_protected_animals.png
보호된 생명 — 관리자가 마지막으로 눈을 감았던 푸른 들판과 꽃이 핀 언덕, 같은 나무 아래의 낡은 고글. 새벽 햇살, 깨끗한 물과 멀리 보이는 보호시설. 관리자는 사후 장면에 등장하지 않는다. 실제 생존 개체는 게임 기록으로 표시하므로 특정 종이나 수를 고정하지 않는다.

### END_13_subject_self_choice.png
자기 선택 (생전 기록) — 살아 있지만 쇠약한 관리자가 마지막 서명을 남기는 장면. 자신이 선택한 삶을 기록하는 조용한 결단.

### END_14_automation_eve_offline.png
EVE의 침묵 — 인격 홀로그램이 꺼진 텅 빈 관제실, 자동 급식 및 점검 장치만 반복 작동.

### END_15_names_memorial.png
마지막 기록 — 어두운 추모 기록실, 비어 있는 사진 틀과 기억을 보존하는 자료 단말. 특정 생존 직원 고정 등장 금지.

### END_16_signal_uncertain.png
응답 없는 하늘 — 폐허 너머로 뻗은 안테나, 검보라 하늘과 희미한 송신 불빛. 수신 성공이나 구조대 도착을 암시하지 않는다.

### END_17_headquarters_aftermath.png
본부 이송의 후폭풍 — M-00 이송 이후 본부의 닫힌 연구시설, 밀폐된 문과 이송 기록 단말. 고양이 생사나 실험 결과를 보여주지 않는다.

### END_18_sanctuary_aftermath.png
보호 루트의 후폭풍 — 비밀 보호실의 평범한 검은 고양이 M-00, 따뜻한 빛 아래 편안한 모습. 변이와 장비 없음.

### END_19_eve_last_memory.png
남겨진 EVE — 관리자의 빈 의자와 낡은 고글을 바라보는 EVE, 새벽 관제실. 슬픔을 간직하고 운영을 이어가는 장면. M-00은 조건부 생존이므로 공용 원화에는 그리지 않는다.

각 엔딩의 후일담과 조건부 분기는 src/lib/ending-sequence.ts에서 결정. 원화 미등록 시 대사 재생은 계속된다. 과거 endings/ 경로는 보조 후보로 유지한다.
