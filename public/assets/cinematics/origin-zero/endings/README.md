# ORIGIN ZERO 메인 엔딩 8장

1600×900 PNG, 16:9. 기존 SCN 시네마틱과 동일한 고밀도 2D 시네마틱 픽셀아트, 검보라/회색과 시안 조명, 인물 외형 일관성. 관리자: 검보라 머리, 분홍 X 고글, 고양이 헤드폰, 검정 테크웨어. EVE: 은백색 장발, 시안 헤드셋, 홀로그램. UI/워터마크/글자 없음. 사후 장면에서 살아 있는 기존 관리자 등장 금지. 생존 여부가 가변적인 직원이나 동물을 고정 등장시키지 않는다.

### END_04_last_zoo.png
관리자가 직접 복원한 넓은 푸른 들판. 새벽 햇살 아래 꽃이 핀 언덕의 나무에 기대어 앉은 젊은 관리자가 평온하게 눈을 감는다. 곁에는 은백색 장발과 시안 헤드셋의 반투명 홀로그램 EVE가 조용히 서 있다. 관리자의 몸 가장자리만 은은한 분홍빛 조각으로 흩어진다. 고글과 헤드폰은 벗어 옆 풀밭에 두고, 폐허·연구실·창문·의료 장비는 등장하지 않는다. 따뜻한 황금빛과 초록색 자연, 해방감과 슬픈 작별. 생존 여부가 가변적인 직원이나 특정 동물은 그리지 않는다.

### END_05_subject_000.png
과학자의 명령을 거부하는 시리우스. 검보라 머리, 분홍 X 고글은 머리 위, 고양이 로고 헤드폰은 목에 걸친 검은 테크웨어의 젊은 관리자. 두려움 속 결연한 표정으로 콘솔의 수평면에 설치된 물리 실행 버튼을 주먹으로 내리친다. 기록 화면 속 최초 과학자는 SCN_15의 검은 머리, 안경, 흰 연구복 외형을 유지한다. 화면의 작은 관리자 이름 필드에 SIRIUS(시리우스)를 이스터에그로 표시하고 인간 복원 프로젝트 재가동 항목에는 붉은 X를 표시한다. 대사, 자막, 대화창은 원화에 넣지 않는다. 실제 대사는 ending-sequence.ts에서 표시한다.
